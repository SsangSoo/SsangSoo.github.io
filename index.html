기존의 러시아어로 구축된 LG전자 카자흐스탄 사이트를 카자흐어를 지원하는 신규 사이트 구축

담당 업무 및 성과

  • 약 200개 테이블의 데이터 구조 및 이관 대상을 분석하고, 약 30~40만 건의 데이터 마이그레이션 수행

  • 해결: Java 기반 SQL INSERT 문 생성 메서드를 개발하여 엑셀 함수 작성 및 반복적인 수작업 최소화

자기소개

Java/Spring 기반 백엔드 개발과 Linux, Docker, Kubernetes 등 인프라 환경 구축 경험을 갖추고 있습니다. 또한 다양한 고객사의 모니터링 솔루션 설치 및 연동을 지원하며 실제 서비스 운영 환경과 시스템의 동작 방식에 대한 이해를 넓혀왔습니다. 이를 바탕으로 애플리케이션뿐 아니라 인프라와 모니터링 관점에서도 기술적 문제를 분석하고 해결하는 역량을 쌓아왔습니다.

LG전자 카자흐스탄 사이트 구축 프로젝트에서는 기존 AEM 기반 배치 및 관리자 모듈의 코드를 분석하고, 신규 언어 지원을 위한 서비스 로직을 확장했습니다. 또한 약 200개 테이블, 30~40만 건의 데이터 마이그레이션 과정에서 반복적인 SQL 생성 작업을 Java 메서드로 자동화하여 테이블당 SQL 작성 시간을 약 85% 단축했습니다.

이후 성능 모니터링 솔루션 엔지니어로 근무하며 약 20~30개 고객사의 JVM, Linux, DB 및 네트워크 환경에서 모니터링 솔루션 설치와 연동을 지원했습니다. 고객사 환경의 문제를 재현하고 검증하기 위해 Kubernetes 테스트 클러스터와 폐쇄망 Harbor 환경을 구축했으며, Keycloak 기반 SSO 연동 과정에서는 Nginx 설정 문제를 분석하고 해결했습니다. 또한 Java 기반 알림 플러그인을 개발하고 AWS CloudWatch의 권한 적용 문제를 발견하여 벤더 제품 개선에 기여했습니다.

저는 새로운 기술을 학습하거나 문제를 분석할 때는 생성형 AI를 적극적으로 활용하되, 실제 실행 결과와 로그를 통해 직접 검증하는 과정을 중요하게 생각합니다. 이러한 방식으로 테스트 환경 구축과 반복 작업의 효율성을 높였으며, Go APM 자동 계측 도구의 비정상 동작을 발견하고 벤더를 통해 제품 버그임을 확인받은 경험도 있습니다.

앞으로도 개발과 인프라, 모니터링 경험을 바탕으로 기능 구현뿐 아니라 애플리케이션의 실행 환경과 시스템 간 연동까지 고려하며, 기술적 문제를 주도적으로 분석하고 개선하는 개발자가 되고자 합니다.
